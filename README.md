# GPT対戦オセロ — ローカルstdio版

[開始案内](START-HERE-ja.md)を開いてください。ゲーム専用プラグインをChatGPTデスクトップへ登録し、このPCのローカル会話の右側で遊ぶ版です。

人が黒をクリックし、その会話のGPTが白を判断します。盤面・ルール・対局状態は各利用者のPC内で管理します。ゲームの接続に公開URL、トンネル、外部AI APIは使いません。GitHubで公開するのは配布用のコードであり、利用者のPCや対局の接続先を公開するものではありません。

## ダウンロードと開始

1. このGitHubリポジトリの **Code → Download ZIP** から取得し、ZIPを展開します。
2. [開始案内](START-HERE-ja.md)に従い、対応するChatGPTデスクトップのローカル会話から `install-plugin.cmd` で準備・プラグイン登録を行います。
3. 新しいローカル会話でプラグインを選び、初回は盤面の「アプリをタブで開く」を押します。以後は黒をクリックすると、その会話のGPTが白を選び、盤面が自動更新されます。

Windows x64での検証用配布候補です。ローカル実行とローカルプラグインが使える環境、および公式ローカルCodex CLIが必要です。全プランへの対応を保証するものではありません。

## 配布の基準

- 再利用元は [tianzhongshenshu382-a11y/gpt-reversi-local](https://github.com/tianzhongshenshu382-a11y/gpt-reversi-local) のPC版0.2.2、固定コミット `013d5b60a45bd99ba39e1036525cccdcfc6b4760` です。
- 対局の13ファイルは、自動往復に成功したインストール済み0.2.2と照合済みです。ゲームコードは変更していません。
- 初回準備はinstall-plugin.cmdです。Node 24.19.0をこのフォルダー内へ取得し、公式SHA256と照合します。npm依存は既存lock固定、install scripts無効で準備します。
- 起動経路はmcp.json → run-stdio.cmd → stdio.mjsです。ツールは新規対局・盤面読取・黒着手・白着手の4件だけです。
- 盤面の「アプリをタブで開く」で、ホスト標準の右側へ表示します。

## 確認範囲

同じWindows PC・同じアカウントの新しいローカル会話で、標準右側表示と、黒D3→同じGPT白C5から始まる7往復（盤面rev14）までの自動進行を確認しました。黒クリック後の追加入力・送信確認・再読み込みは不要でした。

パス・終局・勝敗、不正・重複・古い応答、無応答時の安全停止は同じコードを対象とする局面・結合テストで確認済みです。固定の白着手や疑似ホストを使うテストは、実GPT・実UIの証拠と区別します。

同一環境の一局確認は途中です。別PC・別アカウントの初回導入と一局確認は未実施です。このリポジトリは検証用の配布候補で、第三者向け完成版とはまだ扱いません。登録のみを試した別候補0.2.3と、この0.2.2での動作確認は区別しています。
