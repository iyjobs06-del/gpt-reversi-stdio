# GPT対戦オセロ — ローカルstdio版

[開始案内](START-HERE-ja.md)を開いてください。ゲーム専用プラグインをChatGPTデスクトップへ登録し、このPCのローカル会話の右側で遊ぶ版です。

人が黒をクリックし、その会話のGPTが白を判断します。盤面・ルール・対局状態は各利用者のPC内で管理します。ゲームの接続に公開URL、トンネル、外部AI APIは使いません。GitHubで公開するのは配布用のコードであり、利用者のPCや対局の接続先を公開するものではありません。

## ダウンロードと開始

1. このGitHubリポジトリの **Code → Download ZIP** から取得し、ZIPを展開します。
2. [開始案内](START-HERE-ja.md)に従い、対応するChatGPTデスクトップのローカル会話から `install-plugin.cmd` で準備・プラグイン登録を行います。
3. 新しいローカル会話の入力欄に「@GPT対戦オセロ 各自PC版」と入力し、表示された同名の候補をクリックしてください。名前を文字として入力するだけでは選択されません。選択後、「オセロを開いて。私は黒、あなたは白です。」と送信し、初回は盤面の「アプリをタブで開く」を押します。以後は黒をクリックすると、その会話のGPTが白を選び、盤面が自動更新されます。

Windows x64で7往復、別PC・別アカウントのIntel Macで一局終了を確認した、ローカル配布のたたき台です。ローカル実行とローカルプラグインが使える環境、および公式ローカルCodex CLIが必要です。全プランへの対応を保証するものではありません。

## Macで使う場合

最新版ZIPを展開し、ローカル会話で `/bin/bash install-plugin.sh` の実行を依頼します。登録後は新しいローカル会話の入力欄に「@GPT対戦オセロ Mac版」と入力し、表示された同名の候補をクリックしてください。名前を文字として入力するだけでは選択されません。選択後、「オセロを開いて。私は黒、あなたは白です。」と送信します。候補が出ない場合は、[開始案内のMac手順と制約](START-HERE-ja.md)を参照してください。

Mac専用の起動設定だけを別フォルダーに生成し、ゲーム本体とWindows用の起動設定は変えません。Mac登録版0.2.4での一局終了を確認済みです。初回利用者のプラグイン選択経路には未確認事項があります。

## 配布の基準

- 再利用元は [tianzhongshenshu382-a11y/gpt-reversi-local](https://github.com/tianzhongshenshu382-a11y/gpt-reversi-local) のPC版0.2.2、固定コミット `013d5b60a45bd99ba39e1036525cccdcfc6b4760` です。
- 対局の13ファイルは、自動往復に成功したインストール済み0.2.2と照合済みです。ゲームコードは変更していません。
- 初回準備はinstall-plugin.cmdです。Node 24.19.0をこのフォルダー内へ取得し、公式SHA256と照合します。npm依存は既存lock固定、install scripts無効で準備します。
- 起動経路はmcp.json → run-stdio.cmd → stdio.mjsです。ツールは新規対局・盤面読取・黒着手・白着手の4件だけです。
- 盤面の「アプリをタブで開く」で、ホスト標準の右側へ表示します。

## 確認範囲

同じWindows PC・同じアカウントの新しいローカル会話で、標準右側表示と、黒D3→同じGPT白C5から始まる7往復（盤面rev14）までの自動進行を確認しました。黒クリック後の追加入力・送信確認・再読み込みは不要でした。

パス・終局・勝敗、不正・重複・古い応答、無応答時の安全停止は同じコードを対象とする局面・結合テストで確認済みです。固定の白着手や疑似ホストを使うテストは、実GPT・実UIの証拠と区別します。

別PC・別アカウントのIntel Mac（x86_64）、Mac登録版0.2.4・ゲーム本体0.2.2、ChatGPT Work／GPT-6.1 Sol（中）で一局の終了を確認しました。終局画面は黒52・白0（盤面rev48）。黒クリック後、追加入力・送信確認・再読み込みなしで白が自動反映し終局まで進んだことは利用者報告で確認しました。終局画面の確認と、対局全体の操作に関する利用者報告は区別しています。

Windowsの実対局は7往復までで、終局未確認です。Macの新規会話での候補表示、初見の第三者による導入、Apple Silicon、Windows ARM64、全プラン対応は未確認です。契約プラン名は未記録です。Workでの成功をdotsでの動作保証にはしません。
